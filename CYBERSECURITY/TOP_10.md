# Top 10 — Cybersécurité

Sélection initiale de repositories et ressources à étudier pour développer des compétences solides en cybersécurité.

## P0 — Priorité immédiate

1. **OWASP Cheat Sheet Series** — https://github.com/OWASP/CheatSheetSeries
2. **MITRE ATT&CK STIX Data** — https://github.com/mitre-attack/attack-stix-data
3. **Trivy** — https://github.com/aquasecurity/trivy
4. **Nuclei** — https://github.com/projectdiscovery/nuclei
5. **OSINT Framework** — https://github.com/lockfale/OSINT-Framework
6. **PortSwigger Web Security Academy** — https://portswigger.net/web-security

## P1 — À étudier ensuite

7. **OWASP WebGoat** — https://github.com/WebGoat/WebGoat
8. **Falco** — https://github.com/falcosecurity/falco
9. **Nuclei Templates** — https://github.com/projectdiscovery/nuclei-templates
10. **Awesome Cybersecurity Resources** — https://github.com/Krisztian766/awesome-cybersecurity-resources

## Parcours recommandé

OWASP → Web Security → OSINT → Cloud Security → MITRE ATT&CK

## Règle de sécurité

Les outils de reconnaissance et de scan doivent être utilisés uniquement sur des systèmes pour lesquels une autorisation explicite existe.

## Critère d’étude

Pour chaque projet : objectif, architecture, technologies, installation, niveau requis, labs/exercices, limites, cas d’usage défensifs/offensifs, sécurité, maturité et intérêt pour HashCode Security.
