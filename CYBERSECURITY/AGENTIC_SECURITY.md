# Agentic Security & AI Security

## Pourquoi ce domaine existe
Les agents IA introduisent de nouvelles surfaces d'attaque : outils, mémoire, contexte, MCP, actions autonomes et accès aux données.

## Axes de recherche
- Prompt Injection
- Tool Abuse
- MCP Security
- Agent Memory Security
- AI Red Teaming
- Agent Identity & Authorization
