# Emerging Gems

Cette section contient les projets prometteurs découverts pendant la veille.

## Règle d'entrée
Un projet n'est pas ajouté comme « pépite » uniquement parce qu'il est populaire.

Il doit présenter au moins un signal intéressant :
- innovation technique ;
- forte traction récente ;
- problème important ;
- architecture originale ;
- adoption crédible ;
- intérêt stratégique pour nos axes.

## Cycle
Discovery → Watchlist → Deep Research → Experiment → Decision

Les décisions possibles :
- Étudier
- Utiliser
- Surveiller
- Archiver
- Ignorer
