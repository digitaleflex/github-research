# Contributing

## Ajouter un repository

Toute nouvelle entrée doit inclure :
1. Nom
2. URL officielle
3. Domaine
4. Problème résolu
5. Pourquoi il est intéressant
6. Niveau de maturité estimé
7. Risques ou limites
8. Décision provisoire

## Principe
Pas de collection massive de liens.

Nous recherchons des projets capables d'apporter :
- une compétence ;
- une idée d'architecture ;
- un outil utile ;
- une opportunité de produit ;
- ou une compréhension stratégique d'une tendance.
