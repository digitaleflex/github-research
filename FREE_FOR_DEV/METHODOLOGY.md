# Méthodologie

## Sources
1. Free-for.dev pour la découverte
2. Site officiel pour la vérification
3. Documentation officielle pour les limites
4. Test pratique lorsque nécessaire

## Fiche outil obligatoire
- Problème résolu
- Public cible
- Offre gratuite réelle
- Limites et risques de coût
- Carte bancaire / restrictions géographiques
- Alternatives
- Cas d'usage HashCode
- Score et décision

## Pipeline
DISCOVERED → VERIFIED → EVALUATED → TESTING → APPROVED / REJECTED
