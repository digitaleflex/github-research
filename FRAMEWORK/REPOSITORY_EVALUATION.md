# Repository Evaluation Framework

## Scorecard

### 1. Activité — /10
- commits récents ;
- releases ;
- maintenance.

### 2. Maturité — /10
- stabilité ;
- documentation ;
- adoption.

### 3. Architecture — /10
- qualité de conception ;
- extensibilité ;
- maintenabilité.

### 4. Valeur technique — /10
Le projet apporte-t-il une capacité réellement utile ?

### 5. Sécurité — /10
Permissions, dépendances, isolation et risques.

### 6. Pertinence stratégique — /10
Utilité pour HashCode, E-FLEX ou nos produits.

## Décision finale
- 50+ : Étudier
- 60+ : Expérimenter
- 70+ : Candidat à l'adoption
- score faible : Surveiller ou Ignorer

> Le score aide à décider. Il ne remplace pas le jugement technique.
